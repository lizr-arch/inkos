# 武侠小说建书清单

> 项目暂名：**《无瑕刀》**  
> 内部主题词：**江湖无净土，刀下有底线**  
> 类型：新武侠 / 江湖悬疑 / 门派权谋 / 庙堂江湖 / 成长群像

---

## 0. 基础建书信息（必须）

### 1. 书名（title）

**《无瑕刀》**

备选书名：

1. 《青灯照铁衣》
2. 《刀下无清白》
3. 《照夜刀》
4. 《江湖不渡》
5. 《一刀见青灯》

最终建议使用：**《无瑕刀》**

原因：

- “无瑕”天然有武侠审美：干净、冷、锋利。
- 但主题可以反向展开：江湖里没人真正无瑕。
- “刀”比“剑”更硬，更适合写底层镖局、血案、门派和江湖债。
- 标题短，辨识度高，适合做卷名、武功名、门派旧案核心意象。
- 可以形成全书反复追问：所谓无瑕，是刀无瑕，还是人无瑕，还是杀人的理由无瑕？

## 1. 书级“方向锚点”（强烈建议）

### 8. 作者意图（author_intent）

```yaml
author_intent: >
  写一部新武侠：不是复古地堆门派、秘籍、比武，
  而是写一个年轻人被迫进入江湖秩序的背面，
  在师门旧案、门派利益、庙堂管控和个人仇恨之间，
  一步步明白“侠义不是站在干净一边，而是在脏局里仍守底线”。
```

核心主题：

1. **江湖不是地图，是债务关系。**
2. **侠义不是口号，是代价。**
3. **刀法能分胜负，不能分清白。**
4. **所谓正道，常常只是赢了的人留下的说法。**
5. **主角成长不是武功变强，而是知道什么时候不能杀。**

反主题：

- 不写无脑少年一路打脸。
- 不把名门正派写成全员伪君子。
- 不把反派写成单纯变态。
- 不写“杀光坏人就天下太平”。
- 不把武功写成数值碾压。
- 不让女主成为奖励或花瓶。

current_focus:

第一卷焦点：

第一卷主线问题：

- 镖箱里的人是谁？
- 为什么他“本该死了十七年”？

- 缉武司女捕头闻青灯为什么既追他又救他？
- 沈砚手里的旧刀到底是证据，还是罪证？

### 10. 风格指南（style_guide）

```yaml
style_guide:
  pov: 第三人称有限视角，主要贴沈砚，必要时切配角视角。
  prose: 清爽白话，带一点江湖冷意。
  tone: 冷、利、克制，偶尔有少年热血。
  sentence_style: 中短句为主，打斗用短句，情绪段落可稍长。
  exposition: 世界观必须通过行走、冲突、镖局规矩、门派规矩呈现。
  humor: 少量干冷幽默，来自人物性格，不玩段子。
```

语言范式：

#### 叙述

错误示例：

> 这是一个门派林立、高手如云、朝廷腐败、江湖黑暗的世界。

正确示例：

> 沈砚第一次听见“江湖”两个字，是在镖局后院。那年他十三岁，师父让他把一具死人抬进柴房，又告诉他：行镖的人，不能问货，也不能问死人为什么还热。

#### 对白

- 江湖人说话要带身份。
- 镖师重规矩，话短。
- 门派子弟重名声，话漂亮。
- 缉武司说话像办案，不轻易许诺。
- 漕帮说话带江河气，粗粝但有生意逻辑。
- 老江湖不解释太多，只提醒一句。

#### 禁用表达

尽量避免：

- “他身上爆发出惊天气势”
- “全场震惊”
- “你竟然隐藏了实力”
- “年轻人，你不讲武德”
- “命运的齿轮”
- “江湖这盘大棋”
- “他终于明白了侠义的真谛”
- “刀光如匹练”连续滥用
- “剑眉星目”式模板外貌堆砌

可用意象：

- 雨水、油纸伞、镖旗、马铃、刀鞘、灯油、血锈、渡口、旧账、缠手布、破庙、官印、门派令牌。

### 11. 叙事硬规则 / 书规（book_rules）

```yaml
book_rules:
  - 没有系统，没有修仙，没有法术。
  - 内力存在，但不能治百病、不能无限续航、不能隔山打牛。
  - 轻功存在，但不能飞天遁地，必须受体力、地形、伤势影响。
  - 武功没有绝对数值，胜负受环境、兵器、心理、情报、伤势影响。
  - 打斗必须有代价：伤、累、暴露底牌、结仇、失去机会。
  - 江湖门派受朝廷、钱粮、地盘、香火、弟子来源制约。
  - 没有绝对干净的正道，也没有纯粹为了作恶的反派。
  - 女主和重要配角必须有自己的目标，不能围着主角转。
  - 主角可以变强，但不能靠捡到秘籍直接无敌。
  - 每卷至少一次主角赢了比武却输掉局面。
  - 每卷至少一次主角本可以杀人但选择不杀，或者不想杀却不得不杀。
  - 悬疑线必须公平：关键线索提前出现，不靠结尾硬掰。
  - 旧案真相不能一次性倒出，必须分层揭露。
```

一句硬规则：

> **刀能解决敌人，不能解决真相。**

## 2. 世界观与设定（建议）

### 12. 世界边界与规则（世界观总纲）

```yaml
world:
  dynasty: 架空王朝“大梁”
  era: 承平末年，朝廷尚能压住江湖，但边地、漕运、盐道已经腐坏
  supernatural: none
  martial_level: low_to_mid_wuxia
  geography_scope: 中原、江南、北境、蜀道、东海岛屿
  core_conflict: 江湖自治与朝廷缉武之间的旧平衡正在破裂
```

世界规则：

1. 江湖门派存在，但需要钱、地、弟子、声望和朝廷默许。
2. 朝廷不完全禁止武林，但设有“缉武司”管理大案、兵器、门派冲突。
3. 镖局是江湖与民间、商路、官府之间的缓冲层。
4. 漕帮、盐帮、马帮等帮会既是江湖势力，也是经济组织。
5. 江湖盟名义上维持门派秩序，实际上负责把脏事压成体面。
6. 武功强者可以影响一城一地，但不能靠一个人推翻朝廷。
7. 内功有门槛和损耗，受年龄、经脉、旧伤、药物影响。
8. 秘籍不是万能，没人教、没资源、没时间，练错会死。
9. 真相不是藏在密室里，而是藏在各方都不愿付出的代价里。

武功边界：

| 能做到 | 不能做到 |
|---|---|
| 短时间爆发超常力量 | 永久无消耗连战 |
| 轻功越墙、渡短水 | 像飞行一样跨山河 |
| 内力护住要害 | 刀枪不入 |
| 点穴、闭气、听息 | 远距离心灵感应 |
| 药物续命 | 无代价复活 |
| 老高手经验碾压年轻人 | 无视伤病年龄 |

### 13. 地理 / 势力 / 制度（组织结构）

#### 核心地理

| 地区 | 作用 |
|---|---|
| 青州 | 开局押镖之地，镖局、渡口、旧案入口 |
| 洛水 | 漕运与江湖势力交汇处 |
| 上京 | 朝廷与缉武司中心 |
| 白鹿山 | 江湖盟论剑之地，名门正派聚集 |
| 铁鹞堡 | 北境武人势力，刀法粗厉 |
| 南淮水路 | 漕帮、盐帮、私货线 |
| 蜀道 | 隐门、旧派、药师线 |
| 东海沉刀岛 | 无瑕刀旧主来源 |
| 断碑谷 | 十七年前青灯血案发生地 |
| 青灯镇 | 表面被废弃，实为旧案幸存者藏身地 |

#### 核心势力

| 势力 | 代表人物 | 资源 | 弱点 |
|---|---|---|---|
| 长风镖局 | 陆归鸿、沈砚 | 镖路、人脉、江湖信用 | 武力不如大派，靠规矩生存 |
| 江湖盟 | 裴无咎 | 正道名分、门派协调、仲裁权 | 害怕旧案翻出，体面大于真相 |
| 缉武司 | 岳沉舟、闻青灯 | 朝廷授权、案牍、捕快、牢狱 | 不被江湖信任，受庙堂掣肘 |
| 白鹿书院 | 顾雪衣、谢玄微 | 士林名望、剑法传承、弟子众多 | 过于重名声 |
| 漕帮 | 谢照水 | 水路、钱、船、人 | 与私盐、私货纠缠太深 |
| 青衣楼 | 宁不归 | 情报、暗杀、黑市 | 没有公开名分，人人可用也人人可卖 |
| 铁鹞堡 | 贺兰铮 | 北境骑战、刀法、边地武人 | 粗暴，缺少江南人脉 |
| 沉刀岛 | 秦照夜 | 无瑕刀旧传承、海路 | 与中原断绝多年 |
| 青灯遗族 | 阿蛮、旧案幸存者 | 真相碎片、旧仇 | 分散、弱小、被追杀 |
| 朝廷庙堂 | 首辅、兵部、缉武司上层 | 法统、军队、官府 | 不愿江湖大乱影响漕运和边防 |

#### 江湖制度

- **江湖盟帖**：名义上调停门派冲突，实则可定义“谁是正道，谁是乱党”。
- **镖旗规矩**：押镖不问货，接镖必到，镖在人在，镖失人赔。
- **缉武令**：缉武司签发，对江湖人有拘捕权，但执行需地方官配合。
- **论剑帖**：白鹿山每三年一次，决定年轻一代声望。
- **生死状**：门派私斗合法化工具，但常被用来灭口。
- **江湖黑榜**：青衣楼售卖情报和悬赏，真假混杂。
- **香火银**：小门派向大派或江湖盟缴纳保护费用。
- **刀剑禁运令**：朝廷限制大规模兵器流动，镖局和帮会常钻空子。

### 15. 术语 / 专名词典

#### 武功与兵器

| 术语 | 含义 |
|---|---|
| 无瑕刀 | 一柄旧刀，也是一套刀法名，传说“刀出无冤魂” |
| 青灯式 | 无瑕刀起手式，十七年前血案的关键痕迹 |
| 断水三刀 | 沈砚早期掌握的镖局刀法，实用但粗 |
| 白鹿剑诀 | 白鹿书院传承剑法，重身法与节奏 |
| 铁鹞刀 | 北境重刀法，短促爆发强 |
| 听息 | 江湖人判断埋伏、伤势、呼吸的基础功夫 |
| 缠手布 | 刀客保护手腕、吸汗、止血的布，也常作身份意象 |
| 归鞘 | 无瑕刀最终式，含义不是杀，而是止杀 |

#### 江湖组织

| 术语 | 含义 |
|---|---|

#### 沈砚

```yaml
name: 沈砚
identity: 长风镖局少镖师 / 无瑕刀现持者
age: 20
role: 主角
weapon: 旧刀“无瑕”
```

身份：

- 长风镖局养大的少年镖师。

- 因现场留下无瑕刀法痕迹，被江湖盟认定为杀师凶手。

目标：

1. 第一阶段：活下来，证明自己没杀师。
2. 第二阶段：查清镖箱中人的身份。
3. 第三阶段：找出十七年前青灯血案真相。
4. 第四阶段：面对师父并非全然清白的事实。
5. 第五阶段：决定是否用刀替旧案所有亡者讨债。
6. 终极目标：不让“侠义”变成又一次屠杀的理由。

性格：

- 克制、倔、记账式记仇。
- 不爱说漂亮话。
- 对镖局规矩有近乎执拗的信任。
- 少年气还在，但被现实不断磨硬。

性格缺陷：

- 前期太相信师父。
- 太想证明清白，容易被人牵着走。
- 遇到不公时会压不住杀意。
- 害怕承认自己敬爱的人也有污点。

能力：

- 镖局实战刀法。
- 路线记忆、看货、识人、野外生存。
- 后期习得无瑕刀真正核心：不是快，而是“收”。
- 对江湖人情债有敏感直觉。

底线：

- 不杀无辜。
- 不杀放下兵器的人，除非对方仍会害更多人。
- 不用谎言换清白。
- 不拿死人的名义满足自己的仇恨。

口癖：

- “镖在人在。”
- “这笔账，还没算清。”
- “我不是来讨公道的，我是来问一句为什么。”
- “刀可以落，人不能乱杀。”

成长线：

| 阶段 | 变化 |
|---|---|
| 开局 | 相信规矩，相信师父，相信镖旗 |
| 第一卷 | 发现规矩会被强者改写 |
| 第二卷 | 学会不只用刀，也用证据 |
| 第三卷 | 第一次公开胜过名门子弟，但背负恶名 |
| 第四卷 | 承认师父有错，但不允许别人用谎言审判他 |
| 第五卷 | 能杀很多人，却开始学会收刀 |
| 第六卷 | 不做盟主，不做神话，只做一个能承担选择的人 |

与主线关系：

> 沈砚是江湖旧秩序的受害者，也是可能重复旧秩序的人。他的成长在于：从“证明我清白”，走向“让江湖不能再用清白二字杀人”。

### 19. 故事框架 / 主线承诺（Story Frame）

```yaml
story_frame: >
  少年镖师沈砚在雨夜押镖中被卷入十七年前青灯血案，
  师父被杀，镖局被灭，他被江湖盟定为凶手。
  他带着一柄“无瑕刀”逃亡查案，
  在缉武司女捕头、名门剑客、漕帮少主、情报楼主等人的纠缠中，
  一层层揭开江湖正道当年的封口真相。
```

对读者的五个承诺：

1. **江湖悬疑**  
   每卷揭开青灯血案一层真相。

2. **刀法成长**  
   沈砚从镖局实用刀法，走向真正的无瑕刀，但无瑕刀的终点是收刀。

3. **人物群像**  
   女捕头、名门剑客、漕帮少主、情报楼主、旧案遗孤都有独立目标。

4. **侠义代价**  
   每个选择都不干净，主角必须承担后果。

5. **江湖秩序崩塌**  
   旧案不是一个案子，而是整个江湖盟秩序的地基。

一句主线承诺：

> **沈砚要查的不是谁杀了师父，而是谁有资格用“正道”二字杀人。**

### 21. 节奏原则（Rhythm Principles）

```yaml
rhythm:
  small_hook: every_chapter
  small_payoff: every_3_chapters
  reversal: every_8_12_chapters
  duel_or_action: every_5_8_chapters
  major_reveal: every_volume
```

节奏规则：

1. **每章要有一件正在发生的事。**
   - 押镖、逃亡、追捕、问案、决斗、交易、渡河、夜探、救人。

2. **每 3 章给一个小反馈。**
   - 得到一个名字。
   - 拿到一块令牌。
   - 看穿一个谎言。
   - 赢下一场小打斗。
   - 发现一个旧案碎片。

3. **每 8–12 章必须反转。**
   - 追捕者救了主角。
   - 正道人物撒谎。
   - 黑道人物说真话。
   - 师父的清白出现裂缝。
   - 证据是真的，但解释是假的。

4. **每卷要有一个明确武侠高潮。**
   - 第一卷：镖局血夜。
   - 第二卷：洛水船战。
   - 第三卷：白鹿论剑。
   - 第四卷：青灯镇夜战。
   - 第五卷：江湖盟大乱。
   - 第六卷：断碑谷归鞘。

5. **打斗不能孤立。**
   - 每场打斗都要改变关系、信息或名声。
   - 不能只为了展示招式。

### 22. 章节类型模板

#### A. 押镖章

结构：

```text
接镖规矩
↓
货物异常
↓
路上小试探
↓
镖队内部有人隐瞒
↓
夜里变故
↓
章末货物露出一角真相
```

适合：

- 第一章开局。
- 回忆师父教规矩。
- 后期沈砚重开镖局。

---

#### B. 追捕章

结构：

```text
主角逃亡
↓
追捕者逼近
↓
主角利用地形/镖局经验脱身
↓
发现追捕者其实留了活口
↓
章末两人被第三方包围
```

适合：

- 沈砚与闻青灯前期关系。
- 缉武司与江湖盟同时追杀。

---

#### C. 问案章

结构：

```text
出现证据
↓
证人说谎
↓
闻青灯拆证词
↓
沈砚用江湖经验补细节
↓
证据指向意外的人
↓
章末证人被灭口或主动逃走
```

---

#### D. 比武章

结构：

```text
比武理由不是单纯争强
↓
双方立场先交锋
↓
第一轮试探
↓
暴露一方旧伤或心理破绽
↓
关键招式改变局面
↓
胜负产生新的政治后果
```

注意：

- 打斗前必须有赌注。
- 打斗后必须有后果。
- 不能只写招式名。

---

#### E. 江湖交易章

结构：

```text
一方提出价码
↓
另一方不愿付
↓
出现第三方压力
↓
价码从银子变成人情/名声/证据
↓
交易达成但埋下背叛
```

适合：

- 谢照水线。
- 宁不归线。
- 漕帮、青衣楼、镖行会。

---

#### F. 旧案揭示章

结构：

```text
当前事件与旧案相似
↓
出现旧物：灯、刀、令牌、账册、尸骨
↓
一名当事人说出部分真相
↓
另一份证据推翻他的说法
↓
读者知道更多，但还不是全部
```

---

#### G. 侠义选择章

结构：

```text
主角获得杀人的理由
↓
对方确实有罪
↓
杀人会很爽，也会制造新冤案
↓
同伴给出不同意见
↓
主角选择承担一种不舒服的后果
```

这是本书最重要的章节类型。

### 33. 反“AI味”规则

```yaml
anti_ai_rules:
  - 少用抽象总结，多写具体物件：刀鞘、镖旗、雨水、缠手布、灯油。
  - 不要让角色替作者讲主题。
  - 不要每章都用金句收尾。
  - 打斗要写动作链，不写空泛气势。
  - 江湖规矩要通过事件体现，不要直接百科解释。
  - 每个人说话要带身份，不要全员同一种理性腔。
  - 主角必须会误判。
  - 配角必须有不为主角服务的目标。
  - 悬疑线索必须提前埋，不靠结尾硬补。
  - 每章删除至少一句“看起来很深刻但不推动剧情”的话。
```

禁用高频模板句：

- “这就是江湖。”
- “人在江湖，身不由己。”除非被角色讽刺使用。
- “他终于明白了侠义。”
- “命运从这一刻改变。”
- “全场鸦雀无声。”
- “所有人都震惊了。”
- “他的气势节节攀升。”
- “刀光如雪”反复使用。
- “她美得不像凡人。”
- “这个少年，未来必将震动天下。”

替代方法：

| AI味写法 | 改法 |
|---|---|
| 他终于明白江湖残酷 | 镖旗被踩进泥里，他扶了一次，没扶起来 |
| 全场震惊 | 顾雪衣的剑尖偏了半寸 |
| 刀光如雪 | 刀刃擦过灯油，火苗歪了一下 |
| 她很坚强 | 闻青灯把染血的供词压平，重新按了手印 |
| 反派很有压迫感 | 裴无咎没有拔剑，只让人把盟帖放在沈砚脚边 |
| 主角很愤怒 | 沈砚把缠手布一圈圈解开，又一圈圈缠回去 |

章节自检表：

```text

本章是否有人隐瞒或误判？
本章是否有江湖规矩产生作用？
本章打斗是否改变了局面？
本章结尾是否留下具体钩子？
本章是否删掉了空泛感慨？
```
